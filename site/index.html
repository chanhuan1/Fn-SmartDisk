Fn-SmartDisk

把散落在 smartctl、lsblk、btrfs 里的原始数据整理成清晰、可验证的硬盘健康档案。最大特点是可把冷备机械盘手动切入内核级深度休眠，并在需要时由你亲手唤醒。

最大特点 手动深度休眠 同步 → 安全卸载 → 停转 → 内核 offline，正常运行时不会被飞牛后台访问唤醒

项目最大特点

让冷备盘真正停下来，
而不是等它再次被叫醒

普通待机仍可能被系统扫描、索引或文件访问重新唤醒。手动深度休眠会先保护数据，再把设备从内核层面隔离，让飞牛后台在正常运行时无法再次访问这块盘。

这是明确的手动操作：只在用户确认后执行，正常运行时也只能从本应用手动唤醒。fnOS 重启会让磁盘重新上线。
  1. 01
    同步数据先执行 sync，把尚未落盘的数据写入磁盘。
  2. 02
    安全卸载懒卸载该盘关联的卷，避免文件系统仍处于挂载状态。
  3. 03
    停转盘体机械结构进入停转状态，降低冷备期间的运行与磨损。
  4. 04
    内核隔离写入 device offline，正常运行时只能从本应用手动唤醒。
仅 SATA 机械盘SSD、NVMe 和 USB 桥接盘不会提供深度休眠入口。
风险必须确认系统盘禁止操作；RAID 成员和正在读写的磁盘需要独立确认。
状态可恢复恢复记录原子持久化；异常中断会在下次采集时校正并尝试恢复挂载。

核心功能

从盘面健康、链路状态到电源控制，围绕真实运维场景组织信息。

磁盘健康检测

覆盖 SATA HDD / SSD、NVMe 与 USB 桥接盘，展示中文 SMART 属性、自检历史、ATA 错误日志、设备统计和温度历史。

只读采集

SSD 寿命与主控识别

NVMe 直接读取寿命；SATA SSD 结合主控厂商、属性单位和三星官方 TBW 估算，并明确标注数据来源。

来源可追溯

链路与存储诊断

识别 SATA 降速、PHY 错误、NVMe PCIe 链路、USB 桥接芯片和 btrfs 池错误，同时保留多分支存储链。

早期预警

手动唤醒与安全恢复

唤醒后重扫总线，按 UUID 补挂载，逐项检查原有卷是否恢复，并通过 SSE 实时展示每一步。

仅 SATA HDD

多重保护机制

系统盘禁止操作；RAID 降级和读写中磁盘需要独立确认；恢复数据无法持久化时直接拒绝危险操作。

状态机保护

磁盘备注与操作日志

备注按序列号持久化，换槽位不丢失；电源操作保留环形日志，总览、详情和电源页同步展示。

持久化

休眠盘安全采集

采集和刷新先执行无唤醒电源探测，休眠盘只显示基础信息；只有确认后才读取可能唤醒磁盘的 SMART 数据。

不误唤醒

安装到 fnOS

在应用中心完成安装，不需要额外命令行配置。

1
下载 v1.2.0 安装包从 GitHub Releases 获取最新的 SmartDisk.fpk。
2
从应用中心手动安装打开 fnOS 应用中心，选择手动安装并上传 fpk。
3
打开磁盘高级管理从桌面入口进入，默认通过统一网关 /app/SmartDisk 访问。
SMART 采集为只读操作。电源控制会执行停转、卸载和内核上下线动作，仅适用于已确认的冷备盘；深度下线后需从本应用手动唤醒。
