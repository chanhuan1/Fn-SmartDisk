Fn-SmartDisk

深度扩展飞牛 fnOS 官方磁盘面板：把散落在 smartctl、lsblk、btrfs 里的原始数据翻译成一份专业、可读、可操作的硬盘健康档案，并为冷备盘提供内核级深度下线与唤醒能力。

Go + Vue 3 单二进制 .fpk SATA / NVMe / USB 全介质 中文 SMART 深度解析 冷备盘 深度下线 / 唤醒
下载 .fpk 查看安装指南

核心功能

从盘面健康到电源控制，每块硬盘的完整生命周期都覆盖。

🩺 深度健康检测

全介质覆盖（SATA HDD / SSD、NVMe、USB 桥接盘），完整中文 SMART 属性表 + 厂商专属名 + 关键指标星标。自检历史、ATA 错误日志、设备统计、SCT 温度历史、磁头加载计数一应俱全。

只读采集

🧠 SSD 剩余寿命与主控识别

NVMe 直接读取；SATA SSD 按主控厂商精准识别（群联 / 慧荣 / Intel / 三星），三星盘按官方 TBW 估算并标注来源。主控型号精准到群联 S11/S12、慧荣 SM22xx 等。

主控级精准

🔗 链路与存储诊断

SATA 协商速率 vs 设备最大（掉速预警）、SATA PHY 错误、NVMe PCIe 链路、USB 桥接芯片识别（JMicron / ASMedia / Realtek 等）。btrfs 池错误计数 = 数据静默损坏的早期信号。

早期预警

🔌 深度下线 / 唤醒

懒卸载 → 停转 → 内核 device offline。飞牛后台与文件管理器都无法唤醒，冷备盘利器。唤醒 = running → 重扫总线 → 按 UUID 补挂载，SSE 实时步骤流。

仅 SATA HDD

🛡️ 多重保护机制

系统盘禁止操作；md RAID 成员盘需独立确认阵列降级风险；正在读写的盘需独立确认数据风险。环形 200 条持久化日志，支持一键清空。

强确认

🏷️ 磁盘备注

给每块盘写备注（如「冷备仓库盘 · 3 号位」），按序列号持久化，重启、换槽位不丢失。总览卡片、详情页、电源控制页三处同步显示。

持久化

💤 休眠盘安全采集

首次采集先探测机械盘电源状态，休眠或状态不明的盘只显示基础信息。用户逐盘确认后才读 SMART，避免误唤醒其他休眠盘。

不误唤醒

🖥️ 原生 fpk 桌面集成

以 fnOS 统一网关接入桌面（iframe 窗口 /app/SmartDisk），也可独立端口 8315 直连。深色运维控制台风格，移动端自适应。

fnOS 桌面

安装到 fnOS

三步完成，无需命令行。

1
下载 .fpk 安装包从 GitHub Releases 下载最新的 SmartDisk.fpk 文件。
2
fnOS 应用中心 · 手动安装打开 fnOS 桌面 → 应用中心 → 手动安装 → 上传 .fpk。
3
桌面打开「磁盘高级管理」通过统一网关 /app/SmartDisk 访问，也可通过端口 8315 直连。
⚠️
SMART 采集为只读操作，但电源控制会执行停转、卸载和内核上下线动作。深度下线后飞牛后台无法唤醒，需要从本应用手动唤醒或重启 fnOS。请务必确认是冷备盘再下线。
