# 磁盘高级管理 · Fn-SmartDisk

> 飞牛 fnOS 原生 `.fpk` 应用 —— 让每一块硬盘都被真正看见。

📖 **[在线介绍页](https://fn-smartdisk.pages.dev)** —— 完整功能说明、安装指南、注意事项，一页看懂。

**Fn-SmartDisk** 深度扩展 fnOS 官方磁盘面板：把散落在 `smartctl`、`lsblk`、`btrfs` 里的原始数据翻译成一份专业、可读、可操作的硬盘健康档案，并为冷备盘提供内核级深度下线与唤醒能力。

## ✨ 功能特性

### 🩺 深度健康检测

| 能力 | 说明 |
|------|------|
| **全介质覆盖** | SATA HDD / SSD、NVMe、USB 桥接盘（含读卡器），自动识别接口与透传协议 |
| **SSD 剩余寿命** | NVMe 直接读取；SATA SSD 按主控厂商精准识别（群联 / 慧荣 / Intel / 三星），三星按官方 TBW 估算并标注来源 |
| **SSD 主控识别** | 群联 S11/S12、慧荣 SM22xx、三星、海力士、铠侠、闪迪、金士顿、威刚、浦科特等 |
| **完整中文 SMART** | 全属性中文释义 + 厂商专属名 + 关键指标星标；自检历史、ATA 错误日志、设备统计、SCT 温度历史、磁头加载计数 |
| **链路诊断** | SATA 协商速率 vs 设备最大（掉速预警）、SATA PHY 错误、NVMe PCIe 链路、USB 桥接芯片 |
| **btrfs 池错误** | 读写 / 校验和 / 代际错误计数，数据静默损坏的早期信号 |
| **中文健康评级** | 综合重映射、待处理扇区、CRC、温度、寿命、btrfs 错误 → 优 / 良 / 警 / 危 |

### 🔌 电源控制（仅 SATA 机械盘）

| 能力 | 说明 |
|------|------|
| **深度下线** | 懒卸载 → 停转 → 内核 `device offline`。飞牛后台与文件管理器都无法唤醒，冷备盘利器 |
| **手动唤醒** | `running` → 重扫总线 → 按 UUID 补挂载，实时步骤流式输出（SSE） |
| **保护机制** | 系统盘禁止操作；md RAID 成员盘需独立确认阵列降级风险；正在读写的盘需独立确认数据风险 |
| **操作日志** | 环形 200 条持久化日志，支持一键清空 |

### 🏷️ 磁盘备注

- 给每块盘写备注（如「冷备仓库盘 · 3 号位」），按序列号持久化，重启、换槽位不丢失
- 总览卡片、详情页、电源控制页三处同步显示，总览卡片支持原地编辑

### 💤 休眠盘安全采集

- 首次采集先探测机械盘电源状态，休眠或状态不明的盘只显示基础信息
- 用户逐盘确认后才读取 SMART，避免误唤醒其他休眠盘

## 📦 安装

1. 在 fnOS 应用中心打开「手动安装」，上传 `SmartDisk/SmartDisk.fpk`
2. 桌面出现「磁盘高级管理」入口，通过统一网关 `/app/SmartDisk` 访问
3. 也可通过独立端口 `8315` 直连

> ⚠️ SMART 采集为只读。电源控制会执行停转、卸载和内核上下线操作，读取休眠盘 SMART 前会提示确认。
